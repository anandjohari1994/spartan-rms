## Job Description

We are looking for enthusiastic, creative, and technically motivated UI Developer Freshers to join our development team.

Selected candidates will be responsible for designing, developing, and maintaining responsive, interactive, and user-friendly web interfaces using modern frontend technologies.

Candidates should have a strong understanding of HTML, CSS, JavaScript, responsive design, and basic UI/UX principles, along with knowledge of AI-assisted development tools.

## Roles & Responsibilities

- Design and develop responsive, modern, and user-friendly web interfaces.
- Build reusable frontend components using HTML5, CSS3, JavaScript, Bootstrap, and modern frameworks.
- Convert Figma designs, wireframes, and UI/UX prototypes into functional web pages.
- Ensure cross-browser compatibility and mobile responsiveness.
- Integrate frontend applications with backend REST APIs.
- Identify and resolve UI bugs, performance issues, and layout inconsistencies.
- Collaborate with developers, designers, testers, and project managers.
- Maintain clean, optimized, reusable, and well-documented code.
- Use AI-assisted development tools to improve coding efficiency and problem-solving.
- Participate in code reviews, project discussions, and technical learning activities.
